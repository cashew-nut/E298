# The Whole Site Picture

An interactive slide deck on giving clinical research associates (CRAs) one connected picture of each site, by connecting the data once and surfacing it in the workspaces they already use.

- `site/index.html` is the deck. Open it in a browser. Arrow keys move between slides, N shows speaker notes, T starts the timer.
- `.github/workflows/pages.yml` publishes `site/` to GitHub Pages (Settings > Pages > Source: GitHub Actions).

All study, site and subject data in the deck is illustrative mock data. Quotes are cited to their public sources on each slide.
